# Dr. Cecil · Coming Soon

Static, self-contained academic coming-soon page for **jcecilai.com**.

## Publish on GitHub Pages

1. Open the `cyber2000tech/jcecilai` repository on GitHub.
2. Upload `index.html` and `CNAME` to the repository **root** (not inside a folder). The README is optional.
3. Under **Settings → Pages**, choose **Deploy from a branch** and set **main / (root)**.
4. Under **Settings → Pages → Custom domain**, enter **jcecilai.com** if not automatically populated.
5. In Cloudflare DNS, configure GitHub Pages apex A records and `www` CNAME as described in GitHub's official documentation; use **DNS only** initially.
6. Once DNS validation and certificate provisioning complete, enable **Enforce HTTPS**.

The page needs no build process, dependencies, or API keys. It can replace the placeholder with a full portfolio later.
